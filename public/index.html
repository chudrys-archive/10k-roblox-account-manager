Launch profiles

A profile is a saved bundle of run settings. Applying one changes settings for the next launches. The built-in ones are starting points: use an experiment to check them on your PC.

Script check

Reads the Lua and Luau scripts in a folder and points at patterns that make a long session use more and more memory, such as loops with no wait or connections that are never removed. It is a quick read of the text, so treat a finding as a reason to look, not proof.
